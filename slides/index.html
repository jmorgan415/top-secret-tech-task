Cursor Field Engineer prototype

Unattended vulnerability remediation

A Cursor SDK pipeline that scans, judges, patches, verifies, and opens a draft PR — with a human still on merge.

The problem

CVE dumps arrive whether anyone shipped code.

  • Most findings are transitive noise. A grep of package.json cannot tell you if the app actually calls the vulnerable path.
  • The expensive part is judgment, then a small safe change. Reachable? One-file edit? Did the build still pass?

What I built

Model proposes. Code disposes.

Scan No model
Triage SDK · read-only
Policy No model
Fix SDK · edit, no shell
Verify Rebuild / revert
Draft PR Human merges

Secrets always escalate. Critical never auto-applies. Verify is allowed to undo the agent.
